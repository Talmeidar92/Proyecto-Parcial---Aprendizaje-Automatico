## Descripción del Proyecto
Este proyecto tiene como finalidad aplicar técnicas de Aprendizaje Automático para analizar y predecir el rendimiento académico de estudiantes utilizando el conjunto de datos Student Performance Dataset.

Se desarrollarán modelos predictivos capaces de:

- Estimar la nota final de un estudiante mediante Regresión Lineal.
- Determinar si un estudiante aprobará o reprobará mediante Regresión Logística.


## Objetivo General
Desarrollar modelos de aprendizaje automático para predecir el rendimiento académico de estudiantes a partir de variables académicas, personales y sociales.

## Objetivos Específicos
- Realizar un Análisis Exploratorio de Datos (EDA).
- Aplicar técnicas de limpieza y preprocesamiento de datos.
- Construir pipelines de transformación utilizando Scikit-Learn.
- Implementar modelos de Regresión Lineal.
- Implementar modelos de Regresión Logística.
- Evaluar y comparar el desempeño de los modelos.
- Analizar consideraciones éticas relacionadas con el uso de sistemas predictivos en educación.
